# Decision records

Decision records for Knowledge Islands Design, following the Knowledge Islands decision-record standard. Records are living present-state records: update the record when the decision changes, rather than adding a supersession chain. The design decisions taken so far are recorded in the [design brief](../briefs/design-brief.md) ("Decided 18 Oct 2026") and become records here when the brief is adopted.
