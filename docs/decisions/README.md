# Decision records

Decision records for Knowledge Islands Design, following the Knowledge Islands decision-record standard. Records are living present-state records: update the record when the decision changes, rather than adding a supersession chain. Each record states one decision. Questions that are still open are not records: they are listed in [OPEN.md](OPEN.md), each with its recommendation, until Kit answers them.
