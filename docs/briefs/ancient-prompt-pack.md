# Prompt pack: the Ancient tile set

One prompt per tile in the tile-set contract, ready to paste into an image generator (ChatGPT's image model or similar). The style reference is the chosen picture of Arcadia, [references/arcadia.png](references/arcadia.png) (variation 1, kept unchanged): **attach it to every prompt**, so every tile shares its dusk light and palette, and match its atmosphere first and fix details second ([handoff](arcadia-handoff.md)). Then normalise each result per the [building standards](building-standards.md) and the [Ancient set brief](tile-set-ancient.md).

The first run is packaged as one copy-paste instruction for the ChatGPT or Codex app: [Ancient tiles, batch 1](ancient-batch-1.md) paints the 12 terrains and the hero structures with the exact geometry, sizes and record-keeping. This pack holds the per-tile prompts for the rest of the set.

Shared rules, already inside every prompt: pointy-top hexagonal tile in 2:1 dimetric projection, light from the top-left, a 48-pixel stratified rock plinth, a transparent background for cutting out, no text, no people in close-up, no creatures, no crystals, no magic glow. Generated art is unlicensed until KI-DESIGN-ART-002 is decided, and no prompt names a studio, artist or game.

## Structures (16), thriving state

Generate each structure standing on its typical terrain, then cut the building out. The ids follow the current decisions:

- **The Capital** is `structure/capital`, never the Citadel (`citadel` is only a deprecated alias): the domed Library and the colonnaded Council Hall around an open civic square on a 7-hex flower, civic and never fortified (GDR-KI-PRINCIPAL-011).
- **The Causeway** is `structure/causeway`, never the Bridge (`bridge` is only a deprecated alias): a low stone way on culverts across shallow water, the translation layer (GDR-KI-DESIGN-018). The connector `connector/bridge-span` is a different tile.
- **The Mill** is official: a stone house with a waterwheel, the drawn form of operations (GDR-KI-DESIGN-019).
- **No Tower.** The Tower is retired, so there is no `structure/tower` prompt. **Civic towers** (a clock tower, cloister or college towers) may appear as architecture inside a family, never fortified and never on the Capital's flower (GDR-KI-DESIGN-021).
- **Families are for the five heroes** (Capital, Library, Council Hall, Port, Lighthouse); every other structure is drawn in the set's one shared vernacular ([building standards](building-standards.md#architectural-families)).

The Capital spans a 7-hex flower and the Port an oriented 2-hex pair; every other structure here is a single hex.

## After generating

Save every result unaltered under `+/art/<date>-<batch>/` with a `NOTES.md` recording the exact prompts, pixel sizes and deviations, as [batch 1](ancient-batch-1.md) does. Once a candidate is chosen and normalised, record it in `packages/tiles/sets/ancient/manifest.json` (copy the Modern manifest's ids), with its source prompt, `family` on the heroes and the set's `palette`, so the set can be regenerated or extended consistently.
