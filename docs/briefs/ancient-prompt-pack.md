# Prompt pack: the Ancient tile set

One prompt per tile in the tile-set contract, ready to paste into an image generator (ChatGPT's image model or similar). Generate the [picture of Arcadia](arcadia-picture.md) first and **attach it to every prompt as the style reference**, so every tile shares its light and palette. Then normalise each result per the [building standards](building-standards.md) and the [Ancient set brief](tile-set-ancient.md).

Shared rules, already inside every prompt: pointy-top hexagonal tile in 2:1 dimetric projection, light from the top-left, a 48-pixel stratified rock plinth, plain flat light-grey background for cutting out, no text, no people in close-up, no creatures, no crystals, no magic glow.
